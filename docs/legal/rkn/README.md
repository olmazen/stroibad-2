# Материалы РКН

Каталог подготовлен для будущей работы, но юридические тексты пока не создаются и не считаются согласованными.

## Где что хранить

- `docs/legal/rkn/registry.md` — обезличенный реестр статусов и публичных маршрутов;
- `.private/legal/rkn/` — локальные чувствительные исходники, исключённые из Git;
- закрытое корпоративное хранилище — рабочие сканы, подписи и документы с персональными данными;
- будущий публичный content-source — только окончательно согласованные версии для сайта.

## Процесс

1. Назначить владельца юридической проверки.
2. Заполнить реестр без персональных данных.
3. Подготовить текст в закрытом контуре.
4. Зафиксировать утверждённую версию и дату действия.
5. Отдельным PR добавить публичную обезличенную версию и маршрут.
6. Проверить ссылки из форм/подвала и убедиться, что черновики не попали в `dist/`.

Наличие файла в этом каталоге само по себе не означает соответствие требованиям законодательства. Состав документов определяется отдельным юридическим аудитом на дату публикации.

## Технический блокер перед утверждением

На текущем переходном этапе браузер отправляет текстовые заявки через FormSubmit и вторичный Google Apps Script relay; вложения для этих каналов отключены. Эти каналы должны быть заменены контролируемым российским endpoint до того, как архитектуру обработки заявок можно будет описывать в окончательных документах. Клиентский код уже отделён от транспорта, не показывает ложный success и не хранит локальную историю лидов; выбор оператора, сроки хранения, основания обработки, отдельное согласие и публичные тексты остаются предметом юридического аудита.
