# Legal-документы

В этом разделе хранится только процесс подготовки публичных юридических материалов и обезличенные шаблоны.

Чувствительные исходники — персональные данные, подписи, сканы, договоры, учётные данные — нельзя добавлять в этот Git-репозиторий. Для локальной работы используется игнорируемый каталог `.private/legal/`, для совместной — отдельное закрытое хранилище с управлением доступом.

Публикация юридического документа на сайте выполняется отдельной задачей после утверждения текста. `docs/` никогда не копируется в `dist/` автоматически.
