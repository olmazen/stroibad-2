Описание

Корзина для кондиционера «Астра» — серия Art Deco, узор «Астра» (артикул ART07). Оцинкованная сталь, порошковая окраска по RAL в цвет фасада. Ажурный лазерный узор перетекает по всем граням, закруглённые углы, цельногнутый экран без швов. Изготавливаем под размер вашего наружного блока, поставляем партией на весь объект.

Размер берём от габаритов наружного блока плюс вентиляционные зазоры для отвода тепла. Красим в любой RAL, в том числе в цвет фасада ЖК — вся партия выходит в едином оттенке. Возможно антивандальное исполнение со скрытым крепежом для первых этажей.
